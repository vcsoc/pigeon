# Sidebar groups

Smart Folders and Collections each support named organizing groups.

- Click the new folder-shaped **New group** button beside either section heading, or right-click the heading and choose **New Group…**.
- Right-click a group to create a subgroup, a Smart Folder/collection, or rename it.
- Drag existing items or groups onto a group to nest them. The existing heading-to-root and left-gutter-to-parent moves also work for groups.
- Click a group's name to expand/collapse it. A **Group** badge distinguishes it from ordinary items.
- Groups remain separate within their own section; Smart Folder groups do not introduce filter conditions. Existing Smart Folder parent-rule inheritance remains unchanged.
- Move the contents out before choosing **Remove Empty Group**. This operation never deletes files on disk.

Groups persist with the portfolio. Creating or rearranging these virtual groups does not move physical files.
