# Pigeon 0.3.29

## Faster Privacy And Thumbnail Updates

- Apply privacy changes optimistically to selected thumbnails without waiting for persistence; roll back failed saves without restoring assets that have since become hidden.
- Preserve unrelated metadata edits when an earlier privacy save completes, and fence completion and failure to the original portfolio.
- Reuse decoded thumbnails and privacy masks during warm navigation and scrolling, including ordinary and Blur thumbnails.
- Bound the decoded-thumbnail cache to 64 MiB and 384 entries, prioritize actually viewed thumbnails over read-ahead, and release disconnected resources on eviction.
- Prioritize visible image loads, preempt offscreen prefetch slots when necessary, and avoid repeatedly cancelling the loading drain while scrolling.
- Prepare visible masks during idle time, defer preparation while scrolling, and paint Spoiler canvases before attaching them to avoid repeated layout/compositor work.
- Preserve static, source-coloured Spoiler masks, per-mode strengths, cached Alt reveal, and viewer/magnifier reuse. Uncached thumbnails still require decoding or generation; readiness is not universally instantaneous.

## Settings And Shortcuts

- Give Context Menu Studio its own icon, explanatory title help, and softly tinted borderless dropdowns.
- Place Hierarchy Colors below Thumbnail privacy effect in Appearance settings.
- Filter both configurable and built-in shortcuts, hide unmatched groups, and show a clear empty state.
- Add a configurable Ctrl+Shift+H shortcut for including all subfolder content, with protection against key-repeat toggling.

## Optional Local Semantic Search

- Expose Local Semantic Search in Plugin Manager and require explicit opt-in, including for existing runtime configurations.
- Stop its worker and fence stale results when disabled while retaining models, vectors, and analysis checkpoints.
- Distinguish validated runtime readiness from the mere presence of a Python executable, and clear stale search results when the plugin is disabled.
- The unfinished verified model installer and content-based automatic tagging are not included. Stub-based integration tests do not constitute real-model inference validation.

## Validation And Platforms

- Validated with 966 passing tests and one skipped test, plus dense privacy scrolling, warm navigation, viewer/magnifier, Alt-reveal, static Spoiler, and packaged-file checks.
- Linux and Windows packages are published only after their matching build and package checks pass. macOS requires successful Developer ID signing; an unsigned replacement will not be published.
- Firefox imports of authenticated or hotlink-protected images remain under investigation; this release does not claim a fix.
