# Pigeon 0.2.82 — interaction fixes (prerelease)

- Exclusive sidebar navigation across Smart Folders, collections and physical folders; grid multi-selection is unchanged.
- Indented drop placeholders distinguish sibling placement from moving inside. After markers follow expanded descendants; root/gutter promotions show their destination level. Existing guarded move APIs remain in use.
- Actions refresh Details tags. Removing a tag applies to the selected unlocked assets without focusing autocomplete.
- Pigeon double-Escape return chooses the saved thumbnail window before rendering. Stable scrollbar space prevents a width-induced relayout jump.
- Combine Images: horizontal, vertical, shuffled mosaic and row/column tiling; filenames, ordering, background and proportional size limits. Saves a separate PNG with bounded worker processing and cancellation.

## Validation

535 component tests pass; syntax and whitespace checks pass. Linux and Windows unpacked builds pass 34-file packaged integrity checks; the Windows portable ZIP passes archive validation. Linux packaged empty-profile startup smoke passes (not populated startup certification). Isolated real-Electron interaction checks cover tags, exclusive navigation, all five composition UI modes and a 3,000-item Pigeon return (75ms, exact scroll position 6000 and matching thumbnail window). Worker and IPC tests verify PNG export and source preservation.

Electron sidebar tests check indentation, expanded descendants, root/up-level previews and actual collection/Smart Folder reorder results. Drag events in these tests are programmatic, not native desktop pointer gestures. Physical folder move execution was not newly certified by these preview tests.

## Known limitations

This is not a stable performance certification. The previously reported 40k startup budget failure remains unresolved. Native Save dialog workflows and Windows runtime have not been fully tested. macOS signing/notarization credentials are unavailable. GitHub binary publication is subject to the user's 15-second command limit; a draft or failed upload is not a published binary release.

See `docs/combine-images.md` for format, size and timeout limits. Installed, built and published status must be reported separately.
