# Pigeon 0.3.19 — macOS update and latest search/scroll improvements

- Publishes the latest merged source as a new version, rather than replacing the already-published 0.3.18 tag's older binaries.
- Includes the Semantic results tab's accessible close button, restoring the previous Files view, selection and scroll position without stopping analysis or deleting indexes.
- Displays all semantic matches in a virtualized grid, with a compact results header and no fixed result-count cutoff.
- Improves thumbnail scrolling with keyed card reuse and cached view geometry; includes the latest toolbar title and semantic status improvements.
- Retains immediate manual analysis, configurable automatic inactivity (10 minutes by default), resource caps, and existing portfolio/model data.

## macOS distribution

- Universal package supports Apple Silicon and Intel Macs. ZIP, DMG, blockmaps, update manifest and SHA-256 inventory are published as release assets, not committed binaries.
- The package is signed with the existing **Apple Development** identity matching this installation so built-in **Check for updates** can validate it. It is **not Developer ID signed or notarized**. Production CI signing/notarization requirements are unchanged.
- This release adds macOS distribution; existing 0.3.18 platform packages are not overwritten. Source checks, automated tests, Electron search/close-tab checks, packaged integrity/startup and update compatibility are verified before publishing the macOS manifest.
