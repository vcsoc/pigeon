# Pigeon 0.3.26 — macOS review release

## Changes

- Move **About Pigeon** into the main application menu immediately below **Help**, removing the nested entry while retaining the existing About screen.
- Include **On this day** from the local 0.3.25 review build: images taken or created on today's month and day in previous years, with a live sidebar count, saved navigation, hide/show controls, day rollover and a friendly empty state.
- Prefer the photo's capture date over source-file creation time. Import/edit dates are not substituted, and full EXIF metadata stays outside the lightweight startup stream.
- Include the **All** thumbnail/counter fix: empty saved Smart Folder condition rows no longer reject every asset. Real conditions, null checks and explicit zero/false values remain active.

## Distribution

- Universal macOS ZIP and DMG packages, blockmaps, update metadata and SHA-256 checksums are published as GitHub release assets, not committed binaries. The [macOS checksum record](https://github.com/vcsoc/pigeon/blob/v0.3.26/docs/releases/0.3.26-macos-SHA256SUMS.txt) ties this source release to the exact build artifacts.
- Published as a **preview/prerelease for review and testing**. The stable 0.3.24 release and its existing Windows/Linux packages are unchanged; this release does not claim new Windows/Linux builds.
- Signed with the existing **Apple Development** identity matching the installed app. **Not Developer ID signed or notarized.** Production CI signing/notarization requirements are unchanged.
- Installed `/Applications/Pigeon.app` as 0.3.26, backing up the previous 0.3.25 application bundle. Libraries, settings, models and source files remain in place; the library schema is unchanged.

## Validation

- Clean dependency installation, source/semantic syntax checks and the serialized unit/regression suite passed: **837 passed, 4 skipped**. The suite passed again after packaging and restoring the development dependencies.
- Source UI checks passed for direct About access, On this day, primary sidebar counters, saved All conditions, foreground-thumbnail priority and one-level folder-tree behavior. The packaged source passed the About, memories and counter checks as well, including restart persistence in 34- and 1,202-asset portfolios.
- Packaged clean-profile startup and 84 critical-file/source integrity checks passed. The extracted ZIP satisfies the installed app's signing requirement; the DMG integrity check and updater SHA-512 values passed.
- All nine checked executables/native libraries contain both Apple Silicon and Intel architectures. SHA-256 records cover the ZIP, DMG, both blockmaps and macOS update manifest.
