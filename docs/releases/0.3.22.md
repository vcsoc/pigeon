# Pigeon 0.3.22

- Start physical folder branches collapsed, revealing only the immediate children of branches the user explicitly expands.
- Remove the "Show 500 more..." folder-tree paging control. Load complete folder metadata while rendering only expanded levels so all folders remain reachable without showing the entire hierarchy at once.
- Double-clicking a physical folder collapses that branch and every descendant. Repeating the double-click does not expand the hierarchy again.
- Keep explicit expansions saved per portfolio and start newly discovered branches collapsed.
- Add regression coverage for default collapse, descendant collapse, repeated double-clicks, portfolio isolation, and access to more than 350 folders in the real Electron UI.
