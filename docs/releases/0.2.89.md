# Pigeon 0.2.89 — reliable editor opening, shortcuts, and panel layout

## Fixes and controls

- Background grid rendering previously unconditionally hid the image editor; hiding the scrolled thumbnail grid could itself trigger another virtual-grid refresh. This was reproduced in isolated Electron and fixed: normal refreshes preserve an active editor. Different portfolios, source replacement, deletion, removal, locking, or denied access still invalidate it safely.
- Editor opening immediately shows preparation progress, with a ten-second UI wait limit. Close/Escape cancels the pending opening; source preparation may finish in the background. Late responses cannot reopen a closed editor. Optional AI plugin inspection no longer blocks opening; initialization failures are reported instead of becoming silent rejected promises. Legacy serialized layer arrays and proxy-backed arrays are supported; imported layer IDs and colors are normalized before insertion into the editor.
- **F4: Edit Image. F5: Update selected thumbnails.** Change either in **Preferences → Shortcuts**. Current bindings appear in context menus. Thumbnail rebuilding uses the existing bulk/permission-recovery path and retains Ctrl+Alt+R as an alternate. Remapping F5 does not turn it into browser reload.
- The editor covers the inspector and makes the underlying library inert/hidden without collapsing its layout or changing its scroll position. Its canvas is larger. Tools/orientation controls come first, selected-layer properties and the layer list follow, then image adjustments. Labels and inputs are larger, with aligned fields, visible keyboard focus, and collapsible help/AI enlargement. DOM and visual control order match.

## Evidence

- 598 component tests, including editor-opening failures, nonblocking plugin inspection, cancellation, metadata compatibility, background-paint retention, and source/permission/portfolio invalidation.
- Electron mouse/keyboard tests: opening from a scrolled gallery and retaining the exact scroll on return, F4/F5 defaults, three selected thumbnail files actually regenerated, F8/F9 reassignment, old-key behavior, preferences persisted across a full process reopen, and a real watched-file addition that leaves the editor open. Panel screenshot reviewed; no horizontal panel overflow.
- Blur/pixelate live-strength/move/resize/delete and decoded saved-pixel checks pass, including whole-image rotation and unchanged originals. Crop-over-layer regression passes (418×266 saved output, original unchanged).
- Grid impact is CRITICAL (21 direct callers, 24 indexed flows); settings/menu paths are also shared. The stale graph has incomplete dynamic/new-symbol coverage, so source callers and actual renderer/backend workflows were reviewed directly.

These checks do not certify every native platform, image format, network condition, or historical large-library performance budget. Package integrity, smoke testing, installation, and binary publication are separate release steps.
