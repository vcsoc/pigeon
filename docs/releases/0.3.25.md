# Pigeon 0.3.25 — On this day

## New

- Add **On this day** to the main portfolio sidebar with a calendar icon and live count. It shows images taken or created on today's local month and day in previous years, for a daily look back at past memories.
- Prefer the photo's EXIF original capture date, then digitization/image date, with source-file creation time as a fallback. Import and modification dates are not used as substitutes. Capture dates retain their camera-local calendar day; source birth times use the computer's local timezone.
- Exclude videos, documents, locked items, Trash, this year's images and future dates. February 29 matches only on February 29.
- Support the sidebar visibility checklist and saved navigation. Refresh memories and counts at local midnight and after returning to the app. Show a friendly empty state when there are no matching images.
- Stream only a compact capture date, not full EXIF metadata, and update memories when rebuilt previews reveal a capture date.

## Fixes

- Ignore empty saved Smart Folder condition rows, fixing an empty **All** grid and its zero counter. Preserve real conditions, null/not-null operators and explicit zero/false values consistently in the renderer and main process.
- Add regression coverage for sidebar count/result agreement, loaded thumbnails, live metadata changes and restart persistence in small and large portfolios.

## Local review build

- Build universal macOS ZIP/DMG packages with blockmaps, update metadata and SHA-256 checksums under `release/release-0.3.25-mac-signed/` for review. This local build is not published to GitHub.
- Use the existing **Apple Development** signing identity matching the installed app. **Not Developer ID signed or notarized.** Production CI signing requirements remain unchanged.
- Back up the installed application bundle before replacement. Libraries, settings, model caches and source files remain in place; the library schema is unchanged.
