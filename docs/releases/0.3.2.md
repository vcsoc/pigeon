# Pigeon 0.3.2

- AI Remover has a full-width brush slider, three aligned colorful icon actions with accessible names/tooltips, and icon-based review actions. The unrelated layer color control is hidden while painting a removal mask. Progress updates retain icons.
- Accepting an AI result clears mask pixels and painting state. Late accept responses cannot clear or update a replacement editor session. Failed acceptance retains the mask.
- Viewer images display the cached preview first and upgrade to the original when ready. Minimap uses the cached preview instead of loading a second full-size image. Closed/replaced viewer loads are cancelled.
- Fullscreen return rechecks selected-item visibility after resize settles and avoids unnecessary geometry rebuilds when width has not changed. Repeated/in-flight shortcut transitions cannot race one another.
- Thumbnail load scheduling coalesces redundant requests while retaining four concurrent loads, cancellation, retry, watchdog and scroll priority. An eight-load experiment did not show a consistent throughput improvement and was not retained. No general cold-thumbnail speedup is claimed.
- Uncategorized means no membership in an existing collection and no match in a non-group smart folder (including inherited rules), independently of tags. Untagged means no nonblank tags, independently of collection membership. Entering either view clears stale search/filter/check-only restrictions and shows all matching items rather than hiding stacked members. Counts use the same membership rules.

Validation: 657 unit tests, native AI control layout/mask clearing controls, membership/count checks with 350/3,000 items, fullscreen return with exact scroll preservation and a separate resize/viewer-navigation case, existing editor handle checks. Accept-mask reset and stale-response protection are unit-tested; AI inference itself is unchanged. Fullscreen fixture measured 88ms first paint/144ms total on one run; platform/window-manager transitions and populated/network-library budgets are not certified by this fixture.
