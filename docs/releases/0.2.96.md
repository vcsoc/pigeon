# Pigeon 0.2.96

- Image editor adds Arrow and Circle marker tools with colorful icons and tooltips. Drag from an arrow's tail to its tip (any direction), or drag an ellipse around an area.
- Shapes are editable layers: move, resize, rotate, change color/thickness, rename, delete, Undo/Redo, and Save/reopen. Save retains editable layers; Save as copy commits them to exported pixels. Original files remain untouched.
- Shared SVG geometry keeps editor previews and exported shapes consistent. New shape drawing/movement uses source coordinates under image rotation and flipping.

Validation: native drawing, reverse-direction arrow, resize, Undo/Redo, Save/reopen and original-file preservation. SVG and image-derivative tests verify exported colored pixels and transparent marker interiors.
