# Pigeon 0.3.16 — distribution refresh

This release repackages the current 0.3.15 application with a new version number. There are no application-code or dependency changes.

Included features remain portfolio knowledge graphs, resumable queued semantic analysis, metadata embedding updates, semantic-search controls, and F1 database diagnostics. See [README.md](../../README.md) and the [knowledge graph guide](../knowledge-graph.md) for usage and limitations.

## Distribution

Windows x64 installers/portable executables and Linux x64 AppImage/Debian packages are published with update manifests and SHA-256 checksums. macOS distribution is excluded because the required Developer ID Application signing credentials are not configured. Local unsigned macOS builds are for validation only, not release downloads or automatic updates.

- Source and semantic syntax checks passed.
- The macOS arm64 validation build completed, and packaged integrity checks verified 78 critical files. Basic packaged startup smoke passed.
- The full native test run reported 733 passes, 3 skips and 2 failures out of 738 tests. The startup performance check passed in isolation (4.3 ms maximum synchronous slice). The semantic queue check timed out on this host, where Node reported less than 512 MiB free memory; all 3 queue checks passed with available memory explicitly mocked to 4 GiB. This is not a clean native full-suite result.

Existing dependency audit findings (8 moderate and 8 high) are not addressed by this metadata-only release. Local portfolio data and agent-memory files are not included in the commit or release packages.
