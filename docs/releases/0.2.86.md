# Pigeon 0.2.86 — thumbnail magnifiers and editor cropping

Decoded thumbnail loads and viewport reconciliation now ensure that eligible image/document cards have one magnifier control. This supplements the existing thumbnail-ready callback, so retained cards can recover a missing control without replacement, another rescan, or folder navigation. Locked, permission-denied, uncached and non-previewable assets retain their existing guards.

Crop now takes precedence over annotation-layer hit testing. Previously, starting a crop over a rectangle/text layer silently selected that layer and changed the tool to Select. Crop pointer coordinates now use the editor's pinned asset rather than the grid selection. Normal layer selection remains intact.
