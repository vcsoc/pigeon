# Pigeon 0.2.95

Fix empty space inside thumbnail cards in Rows layout. The preview box now explicitly fills its card's content width instead of deriving a narrower width from its fixed height and aspect ratio. Existing cover rendering, captions, privacy clipping and virtual placement are unchanged.

Native regression reproduces the defect before the fix (526px card / 244px preview), then verifies preview bounds in ordinary and virtualized grids with portrait, landscape and panoramic ratios at two widths and two zoom settings. This supplements 0.2.94's card-placement tests, which did not check the preview inside each card.
