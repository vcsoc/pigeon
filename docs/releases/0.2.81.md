# Pigeon 0.2.81 — prerelease

## Changes
- Indexed folder trees appear before physical-drive discovery completes; saved expansion state is preserved. Late results cannot populate another portfolio.
- Thumbnail captions use font- and line-aware geometry, larger text and higher contrast. Threads text is more readable and wraps.
- Unchanged file notifications are filtered before scheduling root scans; existing-source checks have accurate labels and scan-start diagnostics.
- Includes the accumulated local improvements to scoped automatic tagging, organizing groups, hierarchy dragging, cached previews, concurrent discovery/indexing/previews, duplicate indexes and viewer input handling.

## Validation
- 521 component tests and source syntax checks passed.
- Standalone Chromium caption checks passed for 12 configurations.
- Darkroom's metadata-only tree produced 121 folders from 38,916 indexed assets in 442ms in a worker check; this is not complete portfolio-switch UI timing.
- One actual SMB subtree completed 500/500 persisted, decoded previews in 205 seconds; first preview appeared while indexing was incomplete. Source OS cache was uncontrolled.
- Linux AppImage and Windows portable ZIP built; packaged source verification passed. Windows runtime behavior was not tested on Windows.

## Known limitations
- Last complete 40k regression run still failed startup: 4,385ms against 3,000ms. Scrolling passed that run but longer-term stability is not established.
- Broader seeded smoke failures remain unresolved. Component results do not certify all workflows.
- macOS signing/notarization cannot complete without MACOS_CERTIFICATE_P12, MACOS_CERTIFICATE_PASSWORD and APPLE_APP_SPECIFIC_PASSWORD. No macOS package is included in this prerelease.
- No Debian or NSIS installer is included. Firefox packaging remains unsigned.
- This is a prerelease, not a complete stable cross-platform updater release.
