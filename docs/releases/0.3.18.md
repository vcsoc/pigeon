# Pigeon 0.3.18

- Merged the remote 0.3.16 and 0.3.17 changes before this release.
- Added a small close icon inside the Semantic search results tab, with a tooltip and accessible name.
- Closing results restores the previous Files view, selection and scroll position, removes cached results and match badges, and hides the Semantic tab until another search.
- Supports mouse and Enter/Space activation, including closing from the Files tab. A late response from a search already in flight cannot reopen the closed tab.
- Closing results does not stop portfolio analysis or delete semantic indexes; the query and example remain available for a new search.

## Validation

- Full automated suite: 762 passed, one skipped.
- Syntax/semantic checks and real Electron close-tab tests: restoration, keyboard activation, reopening and late-response protection.
- Linux AppImage and Debian package, update manifest and SHA-256 checksums are published as release assets rather than committed binary files.
