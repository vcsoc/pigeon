# Pigeon 0.3.27

## Changes

- Refresh folder metadata from the existing index after password unlocks and sidebar visibility changes instead of recursively walking source folders again. Cached empty folders remain visible.
- Preserve completed and partial semantic-analysis checkpoints when previews, proxies, or first-time file hashes arrive. Actual source edits, changed known hashes, tags, and notes still invalidate the appropriate analysis.
- Exclude locked and trashed assets from background preview and fingerprint queues, and recheck access before starting queued previews.
- Include the 0.3.26 memories, primary sidebar-count, empty Smart Folder condition, and direct About-menu improvements on Linux and Windows as well.

## Validation

- Regression coverage compares the previous navigation behavior with repeated selections, three folder unlocks, and a collection unlock: the fixed build performs no source scans or recursive folder-tree walks for those actions.
- Checkpoint coverage preserves both completed vectors and partial cursors across cache/hash enrichment while rejecting real content changes.
- Source syntax, serialized unit tests, Electron interaction checks, packaged-source integrity, and clean-profile startup are checked before publication.

## Distribution

- Linux AppImage/Debian and Windows installer/portable packages, update manifests, blockmap, and checksums are distributed as GitHub release assets, not committed binaries.
- macOS 0.3.27 requires the existing production Developer ID signing checks to pass. No older macOS package will be relabeled, and signing requirements will not be weakened. The separate 0.3.26 macOS preview does not include the new unlock/checkpoint fixes.
- Local Linux installation backs up the previous application and portfolio/settings databases while preserving libraries, models, settings, and analysis checkpoints.
