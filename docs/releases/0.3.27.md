# Pigeon 0.3.27

## Changes

- Refresh folder metadata from the existing index after password unlocks and sidebar visibility changes instead of recursively walking source folders again. Cached empty folders remain visible.
- Preserve completed and partial semantic-analysis checkpoints when previews, proxies, or first-time file hashes arrive. Actual source edits, changed known hashes, tags, and notes still invalidate the appropriate analysis.
- Exclude locked and trashed assets from background preview and fingerprint queues, and recheck access before starting queued previews.
- Include the 0.3.26 memories, primary sidebar-count, empty Smart Folder condition, and direct About-menu improvements on Linux and Windows as well.

## Validation

- Regression coverage compares the previous navigation behavior with repeated selections, three folder unlocks, and a collection unlock: the fixed build performs no source scans or recursive folder-tree walks for those actions.
- Checkpoint coverage preserves both completed vectors and partial cursors across cache/hash enrichment while rejecting real content changes.
- Source syntax, serialized unit tests, Electron interaction checks, packaged-source integrity, and clean-profile startup are checked before publication.

### Verified local macOS build

- 842 tests passed, 4 skipped, with no failures; all eight source Electron interaction scenarios passed.
- Packaged About, memories, and sidebar-count checks passed, including 34- and 1,202-asset portfolios. The packaged-source navigation/unlock regression also confirmed zero source scans or recursive folder walks and preservation of cached empty folders.
- 84 critical packaged files, tagged 0.3.27 runtime-source bytes, clean-profile startup, strict signatures, extracted ZIP, and DMG integrity verified. All nine checked executables/native libraries contain both arm64 and x86_64 architectures.
- Updater SHA-512 values and sizes verified. The separate [macOS SHA-256 record](https://github.com/vcsoc/pigeon/blob/main/docs/releases/0.3.27-macos-SHA256SUMS.txt) covers the universal ZIP/DMG, blockmaps, and macOS updater manifest.

## Distribution

- Linux AppImage/Debian and Windows installer/portable packages, update manifests, blockmap, and checksums are distributed as GitHub release assets, not committed binaries.
- Universal macOS 0.3.27 ZIP/DMG packages are locally built from the existing `v0.3.27` tag (`3f6f84c`), signed with Apple Development, and **not Developer ID signed or notarized**. These local-review packages include the new unlock/checkpoint fixes; the older 0.3.26 preview does not. Production CI still requires its existing Developer ID signing checks; no signing requirement is weakened and no older package or tag is relabeled.
- macOS packages, blockmaps, `latest-mac.yml`, and `SHA256SUMS-0.3.27-macos.txt` are added to the existing 0.3.27 GitHub release, not committed as binaries. Existing Linux/Windows assets and their checksum manifest are preserved. Local macOS installation backs up the previous app bundle without replacing libraries, settings, source files, models, or analysis databases.
- Local Linux installation backs up the previous application and portfolio/settings databases while preserving libraries, models, settings, and analysis checkpoints.
