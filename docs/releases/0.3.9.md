# Pigeon 0.3.9 — configurable double-Escape action

- Preferences → Controls → Keyboard now offers three **Esc twice** actions: open the virtual Pigeon Smart Folder and press Esc twice again to return (the previous default); open **All Tags** and press Esc twice again to return; or quit Pigeon immediately without a confirmation dialog.
- The All Tags return restores the originating portfolio view, folder, filters, search, selection, scroll position, and previous navigation controls. Switching portfolios or navigating away does not use a stale return destination.
- A dedicated, sender-checked quit command exits the entire app on Linux, Windows, and macOS rather than only closing the window. Single Escape continues to dismiss dialogs, media viewers, editors, maps, and comparisons; closing one does not accidentally trigger the configured double-Escape action.
- Preferences persist across restarts. Existing users keep the Pigeon-view action unless they change it. The new option does not alter original image files or library metadata.

**Validation:** automated unit tests, an isolated Electron end-to-end round trip through all three actions and preference restart persistence, and packaged Linux verification. The previous 0.3.8 resource-control limitation remains: cooperative background CPU pacing is not a hard combined CPU/GPU ceiling.
