# Pigeon 0.3.1

- Duplicated images persist their source relationship in the library database, keeping copies next to their originals when switching folders, collections and smart folders or restarting Pigeon.
- Rescans retain that relationship, including when an in-flight inspection overlaps duplication.
- Recover placement for older copies in the Duplicates collection whose timestamped filename identifies an original in the same directory. Conflicting known hashes are not inferred as a relationship.
- Linear-time placement handles multiple copies, copies of copies and malformed cycles. Unrelated images retain the selected sort order; sources outside the filtered view are not pulled into it.
- Original files, duplicate naming, location ownership and collection membership are unchanged.

Validation: 651 unit tests; native navigation/rescan/full-process restart checks with 350 and 3,000-image fixtures. Existing missing-location and exclusive-copy collision tests retained.
