# Pigeon 0.3.7 — clear image-editor save actions

- **Save** now writes cropped and edited pixels into the original PNG, JPEG, or WebP file. It preserves the file's permissions, checks for external changes, and restores the original if replacement fails. For other formats, use Save copy.
- **Save copy** exports the current edits into a separate physical file without changing the original or an existing draft.
- **Save draft** retains Pigeon's non-destructive editable version without modifying the original file.
- **Cancel** closes the editor without saving pending changes. Each action has an explanatory tooltip.
- Saved images refresh their dimensions, preview and indexed metadata; full-size and thumbnail previews update without a grid reload.

Validation: 673 unit tests, source checks, and isolated native Electron save/copy/draft/cancel, crop and layered draft workflows. Build artifacts are separate per platform. The local macOS build uses Apple Development signing and is not notarized; it is not a Developer ID public distribution.
