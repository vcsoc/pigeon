# Pigeon 0.2.87 — reliable manual sidebar placement

- Dropping in the gap between a section heading and its first row places a collection/Smart Folder first at root level, including moving an item out of a parent.
- Upper/lower row edges mean before/after across parents; the center still means inside. Drop handlers calculate the final pointer zone rather than falling back to inside when a dragleave cleared the marker.
- Relative moves validate the target and complete sibling order before mutation, reuse existing cycle/name guards, and update parent/order in one IPC operation. Only the destination branch switches to manual sorting. Same-parent collection reorder does not retag or save its images.
- Smart Folder dragleave ignores movement between child elements of the same row. Dedicated heading and left-gutter hierarchy moves remain available; physical folder drops retain their guarded move-inside behavior.
