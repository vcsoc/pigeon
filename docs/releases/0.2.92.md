# Pigeon 0.2.92

- Alpha-preserving PNG thumbnails for transparent originals and WebP edited/AI previews. Preferences → Preview → Thumbnail backgrounds offers transparent, checkerboard, dark, or light display backgrounds. Existing flattened caches need a one-time F5 refresh with originals available; no forced full-library rebuild.
- Editor checkerboard toggle is display-only and never changes exported pixels.
- Per-layer delete icons, editable layer names retained across Save/reopen, and compact contextual layer properties. Deleting a non-selected layer preserves selection.
- Double-click group headings to collapse/expand; Enter/Space also work. Resize and AI enlargement are independent groups; AI enlargement starts expanded.
- Combined image save dialogs default to `pigeon-combined-MMDDHHmmss.png`, using local time.

Validation: 625 unit/component tests; exact decoded alpha checks for original and edited caches; native layer, preferences, group, and transparency checks; native AI alpha and blur/pixelation move/resize/delete regressions. Existing large-library/network/cold-AI/platform validation gaps remain open.
