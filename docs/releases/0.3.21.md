# Pigeon 0.3.21

- Stop semantic analysis panel flicker caused by clearing the current filenames between batches.
- Keep the current batch label visible until the next batch replaces it, and clear it when analysis finishes.

- Add a service regression test for checkpoint notifications and real Electron layout checks at three panel widths.
