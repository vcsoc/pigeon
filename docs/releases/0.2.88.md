# Pigeon 0.2.88 — blur and pixelate image regions

The image editor now has Blur region and Pixelate region tools. Drag a region, move/resize it, and adjust its individual 1–100 strength slider with live preview. Both types can coexist. Drawing selects the finished region automatically; numeric bounds and Delete layer are supported. Unchanged preview canvases are retained during drawing, and preview resources are released when closing the editor.

Save renders effects into the edited PNG while retaining the original file. Committed region controls are removed to avoid double application after reopening. Save copy includes region effects through the derivative renderer. Text/rectangle annotation behavior remains unchanged. See [usage and limits](../editor-region-effects.md), including overlapping-region precedence and the distinction between visual effects and secure redaction.

## Validation

588 component tests, including decoded blur/pixelation pixels, strength differences, unchanged outside-region pixels, alpha preservation, original-file identity, rotated/flipped coordinate conversion, invalid geometry and excessive-region rejection.

Isolated Electron tests use real menu/tool clicks, mouse drawing/moving/resizing, native slider keyboard adjustment, deletion, and Save. Both ordinary and 90-degree-rotated images pass. Captured live-preview regions change with strength; decoded saved pixels change inside both effect regions while pixels outside stay identical to the oriented source. Original file bytes remain unchanged. The crop-over-annotation regression also passes with decoded output and original-file checks.

Editor rendering has CRITICAL graph impact; controls have HIGH impact. New module and dynamic callback edges are not fully resolved in the existing graph and were reviewed directly. These local Linux results do not certify every RAW/EXIF/network/platform combination or the historical large-library performance gaps. Build, installation and GitHub publication remain separate statuses.
