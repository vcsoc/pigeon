# Pigeon 0.3.5

- With a crop selection active in the image editor, press Enter to apply it immediately and continue editing the updated image, fitted to its new dimensions.
- Uses the existing non-destructive save path: pending image edits are saved to the edited copy, leaving the original untouched. Reloading establishes a new editor history base, like reopening after Save.
- Ignores Enter in text/input controls, IME composition and modified shortcuts. Repeated presses cannot start overlapping crop applications. Late results cannot reopen a closed or replacement editor; failures retain pending edits and restore controls.

Validation: focused ownership, failure, keyboard and snapshot tests; native consecutive Enter crops verify decoded output dimensions, current editor image URL, fitted aspect ratio, cleared crop overlay, editor remaining open and unchanged original file hash.
