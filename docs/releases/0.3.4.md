# Pigeon 0.3.4

- Combine Images dialog can be resized from its bottom-right corner, within the application viewport. Preview images fit the available width and height and grow with the dialog, without reloading their image elements or changing export limits.
- Dragging an image shows a tinted destination placeholder with a before/after edge and resulting position. Dropping follows that displayed insertion position; cancellation, leaving the preview and closing the dialog clear the marker.
- Mosaic reordering follows the visible cell sequence rather than the shuffled input indices. Original files and the export pipeline remain unchanged.

Validation: native dialog resize and preview growth, retained image identity, and ten before/after reorder checks covering all five layouts; existing PNG composition/export and cancellation tests retained.
