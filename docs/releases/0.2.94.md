# Pigeon 0.2.94

- F5 rescans the selected sidebar folder (including its selected subfolder), smart folder's eligible indexed sources, or a collection's member directories. New/changed files receive thumbnails through the existing incremental scan pipeline. With thumbnails selected, F5 retains permission-aware thumbnail rebuilding. The shortcut remains configurable.
- Collections retain explicit membership: scanning their source directories does not automatically add neighbouring files. Empty collections without known sources report that no sources are available. Smart folder location constraints are inherited; unrestricted filters may require scanning all indexed sources to discover new matches.
- Justified rows fit within the viewport, including overfull final rows, without shrinking only the final card or overriding narrow virtual cells with the flex layout's minimum width.
- Masonry distributes spare width evenly instead of leaving a right-hand strip, for both virtual and ordinary grids. Incomplete final rows can still have natural trailing space.

Validation: 640 unit tests; native 12-case portrait/wide layout bounds and overlap checks; folder/collection/smart-folder F5 discovery and changed-file thumbnail checks; duplicate visibility; fullscreen return preserving card identity and exact 6000px scroll (82ms first paint in the fixture).
