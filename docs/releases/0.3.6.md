# Pigeon 0.3.6

## Saved image layers

- Save edits now composites all supplied layers into the edited image and its gallery preview, including arrows, circles, rectangles and text—not just blur and pixelation.
- A separate, permission-checked editable base keeps retained vector layers editable without stamping them into the background twice during ordinary repeated saves.
- Save as copy renders all pending pixel operations and layers. Export no longer changes the source asset's stored layers; atomic replacement protects originals behind destination hardlinks/symlinks, and exporting directly over the source is rejected.
- Saving is guarded against overlapping operations and replacement editor sessions. The original file is never modified.

## Built-in All Smart Folder

- All has dedicated, editable Smart Folder conditions, stored per portfolio. Right-click the categories area and choose **Edit All Smart Folder…**.
- All remains pinned to the primary categories area. It cannot be deleted, moved or renamed; use the categories checklist to hide/show it.
- Ordinary/cooperative filtering and the All count use the same saved conditions. All does not contribute to categorization membership, so Uncategorized remains meaningful.
- Existing user-created Smart Folders named All are not converted or removed.

Validation includes decoded Save/Save-as-copy pixels, pending rotation/flip/crop/resize/color/effect operations, ordinary repeated saves, editable reopening, deleting saved arrows, original preservation, and native All conditions/counts/hide-show/deletion protection/restart persistence checks.
