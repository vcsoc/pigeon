# Pigeon 0.3.28

## Context Menu Studio

- Add Settings > Context Menu Studio with independent layouts for thumbnails, images, videos, audio, documents, other files, physical folders, collections and smart folders.
- Promote actions to the root, hide actions, reorder actions and submenus, and create named submenus.
- Preview layouts, apply or save changes, restore defaults, and inherit the thumbnail layout until a file type is customised.
- Preserve the original action handlers, disabled states, permissions and confirmations.

## Privacy Effects

- Add Blur, Pixelate, Glitch, Spoiler and Hidden modes with a default strength of 35 and separately remembered strengths for each mode.
- Replace expensive animated Spoiler rendering with adjustable static, source-coloured masks.
- Cache masks and avoid repainting unchanged thumbnails; retain instant Alt reveal.
- Reuse cached thumbnail masks in the viewer and magnifier before full-resolution originals finish decoding.
- Correct magnifier Blur sizing and clipping, rotated-image bounds, Glitch/Spoiler visibility and dismissal cleanup.

## Resource Usage And Reliability

- Correct worker CPU sampling: use differences between cumulative counters, never treat event-loop activity as CPU usage, and distinguish unavailable counters from genuine zero usage.
- Read the correct heap-memory counter and identify idle database workers.
- Stream and project database-audit records instead of retaining full metadata payloads. Large-library audits no longer require an unbounded full-library allocation.
- Cache expensive database/cache inventories for five minutes, retaining manual refresh and invalidating inventories when access changes.
- Remove redundant full-library JSON serialization from database writes.
- Move semantic coordination into a worker-thread host, with portfolio/access fences and subprocess cleanup. Existing models and index/checkpoint formats are retained.

## Library And File Handling

- Reorder indexed root folders without moving physical folders; save the display order per portfolio.
- Refine sidebar hierarchy controls and expanded-group presentation.
- Support duplication of all selected file types through Ctrl+D, with existing lock/access safeguards and durable persistence.
- Extend subtitle indexing, thumbnails and text previews, including UTF-8, UTF-16 and Windows-1252 decoding, binary rejection and reader access guards.

## Scope And Platform Notes

- Subtitle previews do not attach subtitle tracks to video playback. Bitmap subtitles require an external player.
- Optional semantic-plugin installation and content-based automatic tagging remain in development and are not included in this release.
- The Firefox image-import issue is still under investigation; this release does not claim a fix for authenticated or hotlink-protected downloads.
- Linux and Windows packages are published after their build and package checks pass. A macOS package requires successful Developer ID signing; an unsigned build will not be substituted.
