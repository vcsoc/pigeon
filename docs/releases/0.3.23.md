# Pigeon 0.3.23 — macOS refresh

- Rebuilds the latest merged source for macOS as a new release, without replacing existing version tags or older platform packages.
- Includes the 0.3.20–0.3.22 fixes: semantic checkpoints survive portfolio locks and visibility changes; the analysis panel stays stable between batches; physical folder branches start collapsed, with complete metadata available and explicit expansions saved per portfolio.
- Retains the scrolling and semantic results improvements, immediate manual analysis, configurable automatic inactivity, and existing portfolio/model data.

## Distribution and validation

- Universal macOS ZIP and DMG support Apple Silicon and Intel Macs. Blockmaps, update metadata and SHA-256 checksums are published as release assets, not committed binaries.
- Signed with the existing **Apple Development** identity matching this installation so built-in updates can validate the package. **Not Developer ID signed or notarized.** Production CI signing/notarization requirements remain unchanged.
- Validation covers source checks, automated tests, real Electron folder-tree and semantic feedback checks, packaged integrity/startup, signature compatibility and published update detection.
- The installed macOS bundle is backed up before replacement. Portfolio data, settings, model caches, local annotations and agent files are not bundled or committed.
