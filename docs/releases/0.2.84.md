# Pigeon 0.2.84 — stable scoped views and portfolio return

- Unrelated scan additions/completion no longer rebuild the current grid. Benign resend defaults and source-status URL changes are distinguished from visible changes. Thumbnail dimensions outside the current view no longer trigger its relayout. Membership changes still update the view; unchanged stack badges are not rewritten.
- The drag destination label follows the pointer beneath the native source ghost. The indented insertion line remains at the destination. Context menus still close on drag start.
- Each portfolio restores its saved sidebar destination. Restoration waits for real metadata, rather than treating an empty loading shell as a completed portfolio. Explicit navigation is saved immediately; partial stream paints cannot overwrite it. Missing destinations fall back to All, or the first enabled sidebar option when All is hidden. Offline sources retain their saved scope.

## Validation

560 component tests, including loading-shell, scan relevance, cache retention and unchanged-badge regressions. Linux/Windows builds pass 36-file packaged integrity checks; the Windows ZIP and Linux empty-profile startup smoke pass. Isolated Electron tests:

- Real filesystem saves into an indexed folder excluded by the current collection: two new images indexed/previewed, zero grid renders and zero grid DOM mutations; original card/image identity and geometry retained. Positive control adds one image to the collection and displays it. Fixture: 350 images plus videos.
- Collection, Smart Folder and physical subfolder restored after portfolio switching and closing/reopening the app. New portfolio fallback with All unchecked selects Uncategorized.
- Drag labels stay below the pointer for all three sidebar types; indentation, root/gutter placement and context-menu dismissal remain checked. Drag events are programmatic, not native desktop gestures.
- Existing 3,000-image Pigeon double-Escape check: exact scroll 6000, same thumbnail window, 79ms return.

## Coverage gaps and release status

The larger 3,000-image off-view-save run timed out waiting 3.5 seconds for thumbnail/scan completion; it is not a pass or large-library scan certification. The previous 40k startup budget failure remains unresolved. Native Windows runtime and macOS signing remain unverified/unavailable. Renderer reload is not covered by the successful full-process reopening test.

GitNexus reports critical shared navigation impact; newly added modules are not fully represented in its existing index. Direct source review and targeted tests supplement, rather than erase, this graph limitation.

This is a prerelease. Build, installation and GitHub publication status are separate; binary uploads may exceed the user's 15-second command limit.
