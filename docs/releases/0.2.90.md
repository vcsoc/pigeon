# Pigeon 0.2.90 — automatic AI setup and usable enlargement controls

## Changes

- AI removal now finds or installs managed Python 3.11 with `uv`, without replacing default/system Python. If necessary, an existing Python with pip can bootstrap a pinned `uv` into private storage. Explicit incompatible executable overrides remain errors. Machines without either prerequisite still receive actionable installation guidance.
- Remove object automatically prepares missing runtime/model files and enables the local service. Progress reflects setup, model loading, and inference; Plugin Manager can cancel setup. Incompatible private environments are backed up, interrupted dependency installations are repaired, and a corrupt model is backed up and re-downloaded once. HTTP errors retain partial downloads; wrong ranges and incomplete bodies cannot become completed models. Service starts are deduplicated and cannot finish launching after manager shutdown.
- Late setup/inference results cannot overwrite a different editor session; stale previews are discarded. Rapid repeated clicks cannot start duplicate removal requests.
- The gallery's drag-selection handler was capturing clicks on editor disclosures. Gallery pointer/wheel handling now excludes the editor, native details layout is restored, and both AI enlargement and editor help open normally. Escape closes a modal Plugin Manager without discarding the underlying editor.
- AI Image Enlarger is listed as a bundled, always-available tool in Plugin Manager. Test engine performs real ONNX inference. It requires neither Python nor a separate installation. Damaged bundled application files still require application repair/reinstallation.
- Removal's loopback service rejects browser Origin headers and non-JSON requests before touching filesystem paths. CPU inference is limited to four threads. Images/masks stay local; edited results remain separate from originals.

Cancellation/resume was exercised in bounded foreground batches; download completion used verified byte ranges.
- Actual Python/ONNX inference changed 768 channels inside a 16×16 patch, changed zero outside it, and left the original file unchanged. Browser-origin and plain-text POSTs returned 403/415.
- Isolated Electron: native disclosure clicks preserve selection; modal Escape preserves the editor; the catalog engine test passes; an actual resized/enlarged derivative decodes to 64×40 with the original unchanged. Native removal preview/Accept passed with 42 changed channels inside its small painted mask, zero outside, and the original unchanged.
- The first cold enable-to-preview native test exceeded its 11.5-second wait; the successful native removal run overlaps enabled-service restoration with editor opening. Model startup remains roughly eight seconds on this machine. An experimental runtime cache did not improve it and was removed rather than retaining another model copy.

- Linux/Windows package verification covers 45 critical files. Linux empty-profile smoke passes. F4/F5/remapping/persistence, background-refresh retention, saved region effects, and off-view gallery identity regressions pass.
