# Pigeon 0.3.24

## Improvements

- Selected and visible thumbnails take priority over automatic background indexing and semantic analysis, including when background CPU limits would otherwise delay them. Explicit folder rescans receive foreground priority while pause controls remain respected.
- Folder watchers process debounced, exact file changes instead of rescanning entire folders. New supported files receive background thumbnails and semantic update notifications; atomic saves, incomplete writes, deletions and files arriving during a rescan are handled safely.
- Add **Remove missing** to folder, collection and smart-folder context menus, including descendants. Verified missing references move into Pigeon's Trash; locked, permission-denied and unavailable network/removable sources are skipped.
- Add **Remove missing** to Trash menus to permanently remove missing references without confirmation. Existing source files are never deleted by this operation.
- Privacy-blurred thumbnails keep an opaque backing without changing normal light/dark backgrounds or privacy reveal/disable behavior.
- Double-click a collapsed folder, collection or smart folder to open exactly one level. Deeper branches remain collapsed, and double-clicking an expanded item collapses it and its descendants without affecting unrelated branches.
- Preserve universal macOS packaging and signature verification requirements; see platform availability below.

## Validation

- Serialized unit/regression suite: 826 passed, 1 skipped.
- Electron integration checks cover foreground thumbnails at 95% reported app CPU, manual rescans, incremental image/video detection without folder scans, atomic saves and rescan races, recursive missing-reference cleanup, persistence, source-file preservation, opaque privacy-blur pixels, and real mouse double-click behavior for all three tree types.
- Isolated incremental-watcher tests verify semantic per-file queue notifications; model inference is disabled in those isolated fixtures.
- Packaged startup smoke and critical-file/source verification run before local installation.

Existing libraries, models, settings and analysis checkpoints remain compatible.

## Platform Availability

- Linux x64 AppImage/Debian and Windows x64 installer/portable packages are published with update manifests and SHA-256 checksums. Both platform CI jobs passed for release commit `12be6663438cb369124d2069b14982cf17cce5fe`.
- macOS packages are not included in 0.3.24: GitHub signing credentials are unavailable (`CSC_KEY_PASSWORD` is unset and the certificate input is invalid). No unsigned package or relabeled 0.3.23 binary is published. The older 0.3.23 macOS packages remain available in that release, without these new fixes.
