# Contributing to Pigeon

Bug reports and feature discussions are welcome.

To preserve the copyright holder's ability to maintain Pigeon under both community and commercial licenses, external code contributions are accepted only after a separate written contributor agreement or copyright assignment has been signed. Opening a pull request does not by itself transfer copyright or grant Pigeon permission to relicense the contribution.

Before submitting code, contact **vcsoc@outlook.com** to arrange the appropriate agreement. Pull requests for which no agreement is in place may be reviewed for discussion but will not be merged.

By submitting an issue, you permit the project to use the ideas and information in that issue, but you do not transfer ownership of any separately copyrightable code unless agreed in writing.
