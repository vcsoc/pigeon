# Local AI enlargement model

`super-resolution-10.onnx` is the Super-Resolution Sub-Pixel CNN from the
[ONNX Model Zoo](https://github.com/onnx/models/tree/main/validated/vision/super_resolution/sub_pixel_cnn_2016).

- Model: PyTorch Super Resolution / sub-pixel CNN
- Native scale: 3×
- Source: ONNX Model Zoo, model version 10
- License: Apache-2.0 (ONNX Model Zoo)
- Runtime: ONNX Runtime, CPU only

Pigeon runs this model entirely on the local machine. Images are never uploaded.
